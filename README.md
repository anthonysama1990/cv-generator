# CV-Generator

Optimizá tu currículum de forma fácil. Una landing con un generador de CV que arma un PDF listo para descargar, directamente en el navegador.

**Demo en vivo:** https://cv-generator-gold-kappa.vercel.app

## Funciones

- 6 modelos de CV: Moderno, Clásico, Ejecutivo, Creativo, Elegante y Destacado
- 5 temas de color
- Vista previa A4 en tiempo real
- Foto con editor de recorte circular (arrastrar y hacer zoom)
- Experiencia, educación, habilidades e idiomas
- PDF con texto real y seleccionable, legible por sistemas ATS
- Guardado automático del borrador en el dispositivo

## Privacidad

Todo funciona del lado del cliente: los datos nunca salen del navegador del usuario.

## Tecnologías

HTML, CSS y JavaScript puro, más [jsPDF](https://github.com/parallax/jsPDF) para generar el PDF. Publicado en Vercel.
